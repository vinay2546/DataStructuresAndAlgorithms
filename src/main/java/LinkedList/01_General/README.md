## 22. Edge Cases
Every Linked List solution should explicitly handle:
- Empty list
- Single-node list
- Two-node list
- Head insertion/deletion
- Tail insertion/deletion
- Deleting the only node
- Even vs odd length
- Cycle / circular termination
- Multiple identical values
- Different list lengths
