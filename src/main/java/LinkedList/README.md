# LinkedList

Linked List problems are organized into learning-oriented packages. Each package represents a primary concept or pattern; cross-topic relationships are documented in the individual problem READMEs.

## Package progression

1. `01_Fundamentals` — node structure, traversal, basic operations
2. `02_TwoPointers` — slow/fast pointers and positional pointer techniques
3. `03_InsertionAndDeletion` — mutation, deletion, duplicate removal
4. `04_Reversal` — iterative, recursive, and grouped reversal
5. `05_MergeAndPartition` — merge, split, and partition patterns
6. `06_Arithmetic` — numbers and arithmetic represented by linked lists
7. `07_AdvancedPatterns` — prefix sums, monotonic stacks, sorting, and combinations
8. `08_DoublyLinkedList` — prev/next pointer structures and related designs
9. `09_CircularLinkedList` — circular traversal and manipulation
10. `10_Design` — linked-list data-structure design problems

The package containing a problem is its **primary learning category**. A problem can still involve multiple concepts; those relationships remain documented in its README topics.

## Edge cases to practice

- Empty list
- Single-node list
- Two-node list
- Head/tail mutation
- Deleting the only node
- Even/odd length
- Different list lengths
- Duplicate values
- Circular termination
- Null boundaries

## Learning principle

Learn the package order from fundamentals through pointer manipulation, then combine patterns in the advanced and design packages.
