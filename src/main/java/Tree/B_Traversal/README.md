# Tree Traversal

Traversal is split into two core learning tracks: **BFS** and **DFS**.

## BFS
Use when the problem depends on levels, depth by distance from the root, or processing nodes layer-by-layer.

## DFS
Use when the problem depends on recursion, subtree state, paths, backtracking, or preorder/inorder/postorder relationships.

## Study Order
1. Learn the DFS recursive templates.
2. Learn iterative DFS with a stack.
3. Learn BFS with a queue.
4. Practice level, zigzag, vertical and view traversals.
5. Compare BFS and DFS approaches on problems that support both.

The traversal section intentionally keeps **both BFS and DFS versions** when the repository has both approaches, so the same problem can be used to compare patterns.
